# 数据库表结构文档

## 一、表结构概览

本系统采用经典的 RBAC（基于角色的访问控制）权限模型，共涉及以下五张核心表：

text

```
sys_user (用户表)
    ↓ (user_id → id)
sys_user_role (用户-角色关联表)
    ↓ (role_id → id)
sys_role (角色表)
    ↓ (role_id → id)
sys_role_permission (角色-权限关联表)
    ↓ (permission_id → id)
sys_permission (权限/菜单表)
```



### 权限链路图

text

```
当前登录用户
    ↓
sys_user_role（查询用户拥有哪些角色）
    ↓
sys_role（获取角色信息）
    ↓
sys_role_permission（查询角色拥有哪些权限）
    ↓
sys_permission（获取权限标识 permission_key）
    ↓
生成 Authentication.authorities（Spring Security 权限集合）
```

### 1. sys_user（系统用户表）

#### DDL 建表语句

sql

```mysql
CREATE TABLE `sys_user` (
  `id` bigint NOT NULL COMMENT '主键',
  `username` varchar(30) NOT NULL COMMENT '登录账号',
  `password` varchar(100) NOT NULL COMMENT '登录密码',
  `nickname` varchar(50) NOT NULL COMMENT '用户昵称',
  `phone` varchar(11) DEFAULT '' COMMENT '手机号',
  `email` varchar(50) DEFAULT '' COMMENT '邮箱',
  `status` tinyint DEFAULT '1' COMMENT '状态 0禁用 1正常',
  `create_time` datetime DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `delete_flag` tinyint DEFAULT '0' COMMENT '逻辑删除 0未删 1已删',
  `version` int DEFAULT '1' COMMENT '乐观锁版本号',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_username` (`username`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='系统用户表';
```



#### 字段说明

| 字段名      | 类型         | 约束                                | 说明                 |
| :---------- | :----------- | :---------------------------------- | :------------------- |
| id          | bigint       | PRIMARY KEY                         | 主键（雪花ID）       |
| username    | varchar(30)  | NOT NULL, UNIQUE                    | 登录账号             |
| password    | varchar(100) | NOT NULL                            | 登录密码             |
| nickname    | varchar(50)  | NOT NULL                            | 用户昵称             |
| phone       | varchar(11)  | DEFAULT ''                          | 手机号               |
| email       | varchar(50)  | DEFAULT ''                          | 邮箱                 |
| status      | tinyint      | DEFAULT 1                           | 状态 0禁用 1正常     |
| create_time | datetime     | DEFAULT CURRENT_TIMESTAMP           | 创建时间             |
| update_time | datetime     | DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间             |
| delete_flag | tinyint      | DEFAULT 0                           | 逻辑删除 0未删 1已删 |
| version     | int          | DEFAULT 1                           | 乐观锁版本号         |

### 4. sys_permission（菜单/权限表）

#### DDL 建表语句

sql

```mysql
CREATE TABLE `sys_permission` (
  `id` bigint NOT NULL COMMENT '主键',
  `parent_id` bigint DEFAULT '0' COMMENT '父菜单ID',
  `name` varchar(50) CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci NOT NULL COMMENT '菜单名称',
  `menu_path` varchar(255) DEFAULT '' COMMENT '路由地址',
  `permission_key` varchar(255) CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci DEFAULT '' COMMENT '权限标识',
  `type` tinyint DEFAULT NULL COMMENT '类型 1目录 2菜单 3按钮',
  `sort` int DEFAULT '0',
  `create_time` datetime DEFAULT CURRENT_TIMESTAMP,
  `update_time` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  `delete_flag` tinyint DEFAULT '0',
  `icon` varchar(100) DEFAULT '' COMMENT '菜单图标',
  `component` varchar(255) DEFAULT '' COMMENT '前端组件路径',
  `visible` tinyint DEFAULT '1' COMMENT '是否显示(1显示 0隐藏)',
  `status` tinyint DEFAULT '1' COMMENT '状态(1启用 0禁用)',
  `redirect` varchar(255) DEFAULT '' COMMENT '路由重定向',
```

## 三、核心查询 SQL

### 3.1 查询用户拥有的所有权限标识

sql

```
SELECT DISTINCT p.permission_key
FROM sys_permission p
INNER JOIN sys_role_permission rp ON p.id = rp.permission_id
INNER JOIN sys_user_role ur ON rp.role_id = ur.role_id
WHERE ur.user_id = #{userId}
  AND p.delete_flag = 0
  AND p.type = 3;  -- 只查按钮级权限
```



### 3.2 查询用户拥有的所有角色

sql

```
SELECT r.*
FROM sys_role r
INNER JOIN sys_user_role ur ON r.id = ur.role_id
WHERE ur.user_id = #{userId}
  AND r.delete_flag = 0;
```



### 3.3 查询角色拥有的所有权限

sql

```
SELECT p.*
FROM sys_permission p
INNER JOIN sys_role_permission rp ON p.id = rp.permission_id
WHERE rp.role_id = #{roleId}
  AND p.delete_flag = 0
ORDER BY p.parent_id, p.sort;
```



### 3.4 针对 admin 用户（id=1）的权限查询结果

sql

```mysql
SELECT DISTINCT p.permission_key
FROM sys_permission p
INNER JOIN sys_role_permission rp ON p.id = rp.permission_id
INNER JOIN sys_user_role ur ON rp.role_id = ur.role_id
WHERE ur.user_id = 1 
  AND p.delete_flag = 0 
  AND p.type = 3;
```
